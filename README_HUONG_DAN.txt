HƯỚNG DẪN BÀI TẬP 3-5

Các file mới đã tạo:
- register.html: trang đăng ký nhận thông tin.
- media.html: trang multimedia + semantic HTML5.
- index_new.html: phiên bản semantic HTML5 của index.html.
- css/assignment.css: CSS bổ sung cho các trang mới.
- media/green-event.mp4: video cục bộ dùng cho thẻ video.
- media/interview.mp3: audio cục bộ dùng cho thẻ audio.
- prompt_cau5.txt: prompt dùng cho câu 5.

Cách kiểm tra trên máy:
1. Mở terminal tại thư mục dự án.
2. Chạy: python3 -m http.server 8000
3. Mở trình duyệt và truy cập:
   http://localhost:8000/register.html
   http://localhost:8000/media.html
   http://localhost:8000/index_new.html
4. Kiểm tra form, video, audio, bản đồ và bố cục.

Khi nộp bài:
- Deploy website từ root branch main của repository CN-WEB-DVTT bằng GitHub Pages: https://lamb-is-me.github.io/CN-WEB-DVTT/.
- Giữ nguyên cấu trúc css/, fonts/, images/, media/.
- Điền link host và prompt câu 5 vào file mẫu mà giảng viên yêu cầu.
