# CN-WEB-DVTT

Assignment 02 môn Công nghệ Web và Dịch vụ trực tuyến: website HTML/CSS tĩnh, giữ nguyên giao diện mẫu.

- [index.html](index.html): trang chủ gốc.
- [register.html](register.html): đăng ký nhận thông tin với các input và kiểm tra hợp lệ HTML5 (bài tập tĩnh, không lưu dữ liệu).
- [media.html](media.html): nội dung semantic HTML5, ảnh, video, audio và bản đồ.
- [index_new.html](index_new.html): refactor semantic HTML5 của trang chủ, giữ nguyên nội dung và bố cục.
- Các trang có sẵn: `about.html`, `news.html`, `blog.html`.

GitHub Pages dự kiến: https://lamb-is-me.github.io/CN-WEB-DVTT/

Chạy thử tại root bằng `python3 -m http.server 8000`, sau đó mở http://localhost:8000/.
